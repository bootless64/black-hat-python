# Black Hat Python

A practical learning repository based on the book **Black Hat Python: Python Programming for Hackers and Pentesters** by Justin Seitz and Tim Arnold.

## About This Repository

I've recently started reading *Black Hat Python* to improve my Python programming skills and deepen my understanding of cybersecurity.

This repository is where I'll document my learning journey, implement the examples, and develop the projects introduced throughout the book.

Since I'm just getting started, the repository will gradually grow as I progress through the chapters.

## Goals

- Improve Python programming skills.
- Understand offensive security concepts.
- Explore network programming and security tools.
- Learn about penetration testing techniques.
- Develop practical cybersecurity tools.
- Experiment with and extend the concepts introduced in the book.
